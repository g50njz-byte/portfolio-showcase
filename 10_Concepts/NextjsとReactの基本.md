# ⚛️ Next.js と React の基本

> [!abstract] 📐 ポートフォリオ統括アーキテクトより
> **React** は世界で最も使われているUIコンポーネントライブラリであり、**Next.js** はその上にSSR（サーバーサイドレンダリング）や高速ルーティング（App Router）を統合した最強のフロントエンドフレームワークです。

---

## 🌟 React / Next.js の核となる考え方

1. **コンポーネント指向**:
   * ボタン、カード、ナビゲーションバーなどを再利用可能な部品（Component）として設計。
2. **宣言的UIと状態管理 (State)**:
   * 「データ（状態）が変われば、画面は自動的に同期して描き直される」仕組み。
3. **App Router と 高速SSR**:
   * サーバー側でHTMLを生成して瞬時にブラウザに表示するため、SEO（検索エンジン最適化）とパフォーマンスが最高レベル。
