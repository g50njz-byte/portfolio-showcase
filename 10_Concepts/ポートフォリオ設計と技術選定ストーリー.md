# 📖 ポートフォリオ設計と技術選定ストーリー

> [!abstract] 👑 ポートフォリオ統括アーキテクトより
> 採用担当者やクライアントが最も評価するのは、**「なぜその技術を選んだのか？」「どのような課題をどのように解決したのか？」という意思決定の背景（Why）**です。

---

## 🌟 5大プロジェクトの選定背景とアピールポイント

1. **01. AIデータ分析＆予測ダッシュボード**:
   * 選定理由: データ可視化とリアルタイムシミュレーション需要への対応。
   * 技術: FastAPI の非同期処理 + Pydantic の厳格バリデーション + Chart.js。
2. **02. TaskFlow & 請求書SaaS**:
   * 選定理由: フリーランス・受託の「稼働時間と請求業務の分散」という実務課題の解決。
   * 技術: React のタイマー状態管理 + Flask + SQLite トランザクション + 印刷専用CSS。
3. **03. AURA クリエイティブLP**:
   * 選定理由: ハイエンドブランドの第一印象を高めるモーション＆AI体験。
   * 技術: Vue.js 3 + GSAP ScrollTrigger + Google AI Studio (Gemini 2.0 API)。
4. **04. LUMEN EC＆予約プラットフォーム**:
   * 選定理由: 物販と体験予約を統合した最新のCX（顧客体験）モデル。
   * 技術: React + FastAPI + Stripe決済フロー + カレンダー空き枠判定。
5. **05. メイン総合ポータル**:
   * 選定理由: 全作品を一望できるクリーンで高信頼なエントリーポイント。
