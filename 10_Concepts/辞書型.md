# 辞書型 (dict)

> [!abstract] 一言でいうと？
> **「キー（見出し）」と「値（中身）」をペア**にしてデータを整理・管理するデータ構造です。
> 国語辞典で「単語（キー）」を引くと「意味（値）」が載っているイメージです。

---

## 1. 基本構文・最小コード例

辞書は `{}`（波かっこ）を使い、`キー: 値` の形で書きます。

```python
# 1. 辞書の作成（人のプロフィール）
user_info = {
    "name": "たろう",
    "age": 20,
    "hobby": "プログラミング"
}

# 2. 値を取り出す（キーを指定する）
print(user_info["name"])  # 出力: たろう

# 3. 新しいデータを追加・更新する
user_info["age"] = 21            # 年齢を21に更新
user_info["location"] = "東京"    # 新しいキー「location」を追加

# 4. 安全に取り出す（getメソッド）
# 存在しないキーを指定してもエラーにならず None が返る
print(user_info.get("email", "未登録"))  # 出力: 未登録
```

---

## 2. 重要なポイント

1. **リストとの違い**:
   - **リスト `[]`**: 番号（`0, 1, 2...`）で順番に管理する（例: 順番が大事な待ち行列）
   - **辞書 `{}`**: 名前（キー）で意味を持たせて管理する（例: ユーザー情報、設定値）
2. **キーは重複できない**:
   - 同じキーを2回書くと、後ろの値で上書きされます。
3. **要素のループ処理**:
   - `.items()` を使うと「キー」と「値」を同時に取り出せます。
   ```python
   for key, value in user_info.items():
       print(f"{key}: {value}")
   ```

---

## 3. よくあるミス・注意点

> [!warning] つまずきポイント：存在しないキーを指定したときのエラー（KeyError）
> `user_info["email"]` のように、辞書に存在しないキーを直接指定すると **`KeyError`** というエラーが発生してプログラムが止まってしまいます！
> 
> **対策**:
> - キーが存在するか確認する: `if "email" in user_info:`
> - `.get()` メソッドを使う: `user_info.get("email", "デフォルト値")`
