# 04_Security_Spec: UVU SUPPLY CO.

本ドキュメントは、「UVU SUPPLY CO.」のWebサイトプロトタイプ開発におけるセキュリティ設定および対策を定義する。

## 1. 環境保護とリポジトリ管理
- **Git管理の除外設定**:
  - 不要なキャッシュや、将来的に追加される可能性のあるAPIキーなどの機密情報を保護するため、ルートディレクトリに `.gitignore` を設置する。
  - `.gitignore` 対象: `.env`, `node_modules/`, `.DS_Store`

## 2. フロントエンド脆弱性（XSS/CSRF）対策
- **XSS（クロスサイトスクリプティング）の防止**:
  - ユーザー入力（メルマガ登録フォームなど）を受け取って画面に表示・処理する際、絶対に入力値をそのまま `innerHTML` や `eval()` などで処理しない。
  - JavaScriptでの文字列の代入には、安全な `textContent` または `innerText` を用いて、ブラウザ側で自動的にエスケープされるようにする。
- **入力値バリデーション**:
  - メールアドレスフォームなどの入力において、フロントエンド側でパターンマッチング（HTML5の `type="email"` やJSによる簡易バリデーション）を行い、異常な値の送信を防ぐ。
