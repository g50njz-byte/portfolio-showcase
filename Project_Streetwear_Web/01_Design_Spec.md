# 01_Design_Spec: UVU SUPPLY CO.

本ドキュメントは、「UVU SUPPLY CO.」のフロントエンド実装におけるデザイン仕様を定義する。

## 1. コンセプトとトーン＆マナー
- **コンセプト**: NY×Tokyo（渋谷・裏原宿）のストリート/HIP HOPカルチャーを融合させたアパレルブランド
- **世界観**: 無機質なコンクリート、洗練されたダークモノトーン、エッジの効いたスタイリッシュさ
- **余白設計**: 情報を詰め込みすぎず、広めのマージン（余白）を確保し、プレミアム感のあるハイエンドストリートブランドの印象を演出する。

## 2. カラーパレット
- **ベースカラー**: `#111111` (リッチブラック。全体の背景、重厚感の演出)
- **メインカラー / テキスト**: `#FFFFFF` (ピュアホワイト。高いコントラストを確保)
- **アクセントカラー**: `#888888` (コンクリートグレー。境界線、サブテキスト、ホバーエフェクト)
- **その他**: サブサーフェスとして `#1a1a1a` などの暗いグレーを用いて、カードやヘッダーの立体感を出す。

## 3. タイポグラフィ
- **見出しフォント**: `Futura`, `Helvetica Neue`, `Arial`, sans-serif (太めのサンセリフ体で力強くインパクトを持たせる。英字はすべて大文字 `uppercase` を推奨)
- **本文フォント**: `'Inter'`, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif (可読性を重視したシンプルなサンセリフ)

## 4. レイアウト＆コンポーネント設計
- **グリッドシステム**:
  - 商品カテゴリやLookbookは CSS Grid を用い、PCでは非対称なグリッド、または2〜4カラムの可変レイアウトとする。
  - スマートフォン表示時は1〜2カラムに最適化する。
- **ホバーエフェクト (マイクロインタラクション)**:
  - ボタンや商品カードは、ホバー時にわずかに浮き上がる（`transform: translateY(-4px)`）か、不透明度が変化する（`opacity: 0.8`）、またはボーダーの色が変化するスムーズなトランジションを設定する。
