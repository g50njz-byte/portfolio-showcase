# ポートフォリオ公開前 セキュリティチェックリスト

Webサイト・ポートフォリオをインターネット上に公開（デプロイ）する前に、以下の項目を一つずつチェックしてください。

---

## 🟩 1. 機密情報・プライバシーのチェック
- [ ] **ハードコードのチェック**:
  - `script.js` や設定ファイル内に、パスワード、APIキー、プライベートなメールアドレスが直接書き込まれていませんか？
- [ ] **環境変数 `.env` の分離**:
  - APIキーやシークレットは `.env` に移動され、`.env.example` のみがテンプレートとして用意されていますか？
- [ ] **ダミー情報の書き換え**:
  - 本文中の住所や連絡先が、実害のない公開用情報（またはダミー）に置き換わっていますか？
- [ ] **テスト用・一時ファイルの除外**:
  - 開発中に一時的に作成したメモファイルや未使用のソースコードが残っていませんか？

## 🟨 2. クライアント案件 (NDA) & 著作権のチェック
- [ ] **公開許可の取得**:
  - 掲載している作品の中に、クライアントの明確な許可を得ていないものはありませんか？
- [ ] **商標・ロゴの利用**:
  - クライアント企業や他社ブランドのロゴマークを無断で使用していませんか？
- [ ] **コードの隠蔽**:
  - クライアントの商用コードや非公開アルゴリズムがフロントエンドの JavaScript や公開リポジトリに含まれていませんか？

## 🟦 3. フォーム・通信・スクリプトの安全対策
- [ ] **入力値サニタイズ＆バリデーション**:
  - お問い合わせフォームに適切な入力チェックおよび XSS 対策（`textContent` 使用またはエスケープ処理）が施されていますか？
- [ ] **スパム対策・CSRF対策**:
  - フォームにスパム対策（reCAPTCHA等）や CSRF 防止策が講じられていますか？
- [ ] **Subresource Integrity (SRI) の設定**:
  - CDNから読み込んでいる外部 JS/CSS に `integrity` 属性および `crossorigin="anonymous"` が付与されていますか？
- [ ] **HTTPS（暗号化通信）**:
  - 公開先サーバーで SSL/TLS 証明書が有効化され、`https://` で安全に通信が行われるようになっていますか？

## 🟥 4. Git・インフラのチェック
- [ ] **.gitignore の適用**:
  - プロジェクトルートに `.gitignore` が配置され、`.env`, `.DS_Store`, ログファイル等が除外されていますか？
- [ ] **リポジトリの公開設定**:
  - 未完成または機密情報を含むリポジトリが誤って「Public」公開されていませんか？
