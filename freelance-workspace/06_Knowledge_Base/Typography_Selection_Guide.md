## 2. Web制作・UIデザインにおける組み合わせパターン

※CSS指定時は必ず「欧文フォント ➔ 和文フォント」の順で記述してください。

| サイトのテイスト | 欧文フォント | 和文フォント | CSS `font-family` 指定例 |
|---|---|---|---|
| **モダン / SaaS / テック** | Inter / Roboto | Noto Sans JP | `'Inter', 'Noto Sans JP', sans-serif` |
| **信頼・ビジネス・コーポレート** | Segoe UI / SF Pro | 游ゴシック / ヒラギノ角ゴ | `'Segoe UI', 'Yu Gothic', 'ヒラギノ角ゴ ProN', sans-serif` |
| **高級感・エレガント・メディア** | Playfair Display / Garamond | 游明朝 / Noto Serif JP | `'Playfair Display', '游明朝', 'Noto Serif JP', serif` |

## 4. プレゼン資料・企画書スライド用フォント（視認性＆互換性最優先）

- **鉄則**: 明朝体は避ける（プロジェクター投影で細い線がかすれるため）。
- **推奨組み合わせ**:
  - **メイリオ + Segoe UI**: Windows標準・万人向けスライドの鉄板。
  - **ヒラギノ角ゴ + SF Pro**: Mac/Keynote向け。洗練されたデザインピッチ資料。
  - **BIZ UDPゴシック + Arial**: ユニバーサルデザイン (UDフォント)。
