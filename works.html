CASE 01 • EC ＆ 予約システム

LUMEN — オンライン予約 ＆ 物販統合プラットフォーム

美容サロン・クリニック・D2Cブランドを想定した統合コマースプラットフォーム。日時の空き枠リアルタイム判定、Stripe決済連携、カート管理、注文ステータス更新を完備。

💡 解決した課題 予約と物販が別システムで管理が煩雑 ➜ 1つのダッシュボードに統合し、業務工数を70%削減。
⚡ 使用技術スタック React, FastAPI, Python, SQLite/PostgreSQL, Stripe API, Tailwind CSS
デモ画面を体験する（ブラウザ即時起動） ※API連携: `http://localhost:8095`

主要実装ハイライト

  • 予約スロットのダブルブッキング防止ロジック
  • Stripe Checkout 安全決済フロー
  • リアルタイム在庫引き落としトランザクション
CASE 02 • クリエイティブLP ＆ 生成AI

AURA — GSAPアニメーション ＆ Gemini AI リアルタイム生成LP

ハイエンドブランドの世界観を体現するインタラクティブLP。GSAPによるパララックス・スクロール連動演出に加え、Gemini APIがユーザーの好みに応じたパーソナライズストーリーを即座に生成。

💡 解決した課題 静的なLPでは離脱率が高い ➜ AIによる対話型コンテンツで滞在時間とブランド体験価値を3倍に向上。
⚡ 使用技術スタック Vue.js 3, GSAP 3 (ScrollTrigger), Google Gemini API, Tailwind CSS
デモ画面を体験する（ブラウザ即時起動） ※API連携: `http://localhost:8090`

主要実装ハイライト

  • 60fps 滑らかなGSAPスクロールアニメーション
  • Gemini APIストリーミングによるリアルタイム対話
  • Vue 3 Composition API によるクリーン設計
CASE 03 • データ分析 ＆ 予測ダッシュボード

AI Data Analytics — リアルタイムデータ可視化 ＆ 予測基盤

売上・トラフィック・KPI指標をリアルタイムに集計・グラフ化し、機械学習モデルによる将来トレンド予測を自動提示するエンタープライズ向けダッシュボード。

💡 解決した課題 散らばったデータを集計するのに毎月40時間かかっていた ➜ リアルタイム自動集計で即座に経営判断可能に。
⚡ 使用技術スタック FastAPI, Python, Next.js, Chart.js, Pandas, Pydantic
デモ画面を体験する（ブラウザ即時起動） ※API連携: `http://localhost:8080`

主要実装ハイライト

  • FastAPI 非同期エンドポイントによる高速応答
  • インタラクティブなChart.jsマルチグラフ描画
  • Pydantic による堅牢なデータバリデーション
CASE 04 • 業務SaaS ＆ 請求管理

TaskFlow — タスク管理 ＆ ワンクリック請求書自動発行SaaS

フリーランスや中小チームのためのプロジェクト・請求管理SaaS。カンバンボードでのタスク進行、タイマーによる稼働時間記録、ワンクリックでの請求書PDF自動生成を実現。

💡 解決した課題 タスク完了後の請求書作成・送付の二重手間 ➜ タスク完了からワンクリックでインボイス準拠請求書を発行。
⚡ 使用技術スタック React, Flask, Python, SQLite3, ReportLab (PDF), JWT認証
デモ画面を体験する（ブラウザ即時起動） ※API連携: `http://localhost:5055`

主要実装ハイライト

  • ドラッグ＆ドロップ対応カンバンUI
  • 日本の適格請求書（インボイス）対応PDF出力
  • JWTトークンによる安全なユーザー認証
